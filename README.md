# jossman14.github.io

Situs portofolio pribadi Tanzilal Mustaqim (peneliti Computer Vision/Deep Learning dan Full-Stack Developer), di-host dengan GitHub Pages.

## Isi Halaman
About, Projects, Research, Publications, Contact.

## Tech Stack
HTML + CSS + JavaScript dalam satu file `index.html` (font dari Google Fonts), tanpa build step.

## Struktur
- `index.html` — seluruh halaman
- `profile.png` — foto profil

## Menjalankan
Buka `index.html` di browser, atau push ke branch `main` untuk dipublikasikan lewat GitHub Pages.
